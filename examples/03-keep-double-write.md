这一页要一个决定：双写继续开着，还是关掉。切读已经稳定跑了六天，
旧缓存那边现在只有一个任务在读。

## 两边的代价

| | 保留双写 | 关掉双写 |
|---|---|---|
| 回滚能力 | ok 秒级切回旧缓存 | warn 需重建，约 40 min |
| 写入放大 | no 每次写两份 | ok 省 47% 写 |
| 报表任务 | ok 不受影响 | 需先改读新缓存 |
| 心智负担 | no 两套开关要同时维护 | ok 只剩一条路径 |

## 建议

```ask

* 先改报表任务，两周内关双写 | 回滚窗口用重建的 40 分钟换 47% 的写放大
- 保留双写到下季度 | 报表任务排不上期，就先忍着
```
